Hello, 

this is the start of our casptone project. 

You will see the following structure (with changes if i have forgotten to update this section):  

```
.
├── data/                    - parameters, csv files, oscilloscope data
├── docs/                    - documentation of our project
├── hardware/                - KiCad Project files, scheamtic, footprints, etc.
│   ├── schematics/             - schematic files
│   ├── layout/                 - PCB layout files
│   ├── libraries/              - custom footprints/symbols
│   └── manufacturing/          - gerbers, BOM, etc.
├── models/                 - main simulink directory
│   └── components/              - smaller components for the model
├── scripts/                 - utility matlab scripts
├── src/                     - C code
└── work/                    - MATLAB throws autogenerated files in here 
```

# How To Use This Code
1. git clone this repo: 
```
git clone https://github.com/abd-alaj/BLDC-motor-custom-inverter.git
```
2. run the `init_proj.m` script in matlab prior to starting any work. 

That's it. This project is in a rather primitive state so this readme file is an active WIP.
